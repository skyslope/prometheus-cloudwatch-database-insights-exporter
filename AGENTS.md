## Threat model

Consult [docs/threat-model.md](docs/threat-model.md) and update it when changes affect security assumptions or trust boundaries.

## Keep documentation current without journaling

When updating documentation such as `THREAT-MODEL.md`, edit the relevant
sections to describe the current system. Do not append dated update notes,
session logs, change diaries, or summaries of the edits you made. Git history
records those changes. Add a changelog or journal only when explicitly
requested.
